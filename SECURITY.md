# Security policy

## Supported versions

Tijdens de alpha- en bètafase wordt uitsluitend de nieuwste prerelease ondersteund. Vanaf `v1.0.0` vermeldt de compatibilitymatrix welke release-lijnen securityfixes ontvangen.

## Kwetsbaarheid melden

Publiceer geen tokens, interne URLs, entity-ID's, locaties, camerabeelden of configuratie-exports in een publiek issue. Meld een kwetsbaarheid via GitHub Private Vulnerability Reporting in deze repository. Beschrijf impact, getroffen versie en reproduceerbare stappen met fictieve gegevens.

## Scope

Relevante meldingen zijn onder andere ongeautoriseerde servicecalls, ontbrekende confirmations, privacylekken, supply-chainproblemen, configuratie-exportlekken en cross-site scripting in de strategy of editor.
